# Collections & User-Generated Content

## Collections

Every account (including guest) gets **Favorites** lazily on first collection interaction; it is not deletable. Full accounts can create additional private collections.

## Roles

Owner (full control), Editor (add/remove memes, invite viewers), Viewer (read-only).

## Sharing

Via invite links. Shared as Mini App deep links in Telegram: `t.me/memexpertbot/app?startapp=invite_XXXXX`. No public collections at launch.

Invite links must be usable from web, bot PM, and Mini App. Accepting an invite grants the selected role and makes that collection searchable/browsable for the new member.

## Search and Filtering

Private and shared collections are first-class search scopes:

- Web search can filter public/common only, private/shared only, all accessible content, or specific private/shared collections.
- Bot inline search uses the same accessible scope after resolving the Telegram account.
- Collection-scoped search still enforces role/access checks in PostgreSQL before returning display data.

## Pins

Up to 20. Shown first in inline empty query. Full accounts only. Web profile supports drag-and-drop reorder.

## Like = Favorite

Liking a meme adds it to the Favorites collection. The total like count (number of unique users who favorited) is displayed publicly on the meme page. This count also feeds into popularity scoring and trending calculations.

## User Uploads

Users upload memes to collections. Uploads are:

- **Private by default** — collection membership, not upload provenance, grants access
- **Globally exact-deduplicated by SHA-256** — matching any file reuses the canonical meme/file, adds a source record, and adds the meme to the target collection; this includes private memes uploaded by another user
- **Public exact matches stay public** — saving/uploading the same bytes never makes a public meme private
- **Approximate public matches remain separate private memes** — intentional public/private near-duplicates are allowed when bytes differ
- **Approximate private matches merge only for the same sole uploader** — shared or cross-user private memes never merge by pHash/embedding similarity
- **Deduplicated within target collection** — no duplicate entries
- Processed through transcoding + OCR + embedding pipeline
- No SEO pages generated by default
- Private content is visible/searchable only through collection ownership or membership
- Canonical uploader/source metadata is informational and absent from non-admin responses
- Deleted from storage when removed from all collections

If a public crawler later discovers the exact SHA of an automatic private upload, the same canonical meme is promoted to public while all existing collection saves remain. An admin `force_private` policy prevents that promotion.

## Moderation

Private collections: not auto-moderated. "Report" button for members. Admin manual review.
